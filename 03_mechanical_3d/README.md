# 03 · 机械结构 3D 模型

车载平衡滚球小车的**完整机械设计**：底盘、车架、舵机支架、摆杆机构、视觉支架。
全部零件均为自主建模，可直接用于 3D 打印或加工。

- **CAD**：SolidWorks（`*.SLDPRT` 零件 / `*.SLDASM` 装配体）
- **交换格式**：`printables_step/` 下提供 9 个 `*.STEP`，用于打印切片或跨软件打开

---

## 目录结构

```

```

## 机构设计要点

**摆杆俯仰机构**：舵机旋转 → `舵盘摆臂杆` → `摆杆撑杆` → 摆杆绕 `摆杆支撑转轴座`
俯仰。舵机脉宽与倾角近似线性（`500–2500us` 对应 `0–180°`），
主控侧的水平点标定值为 `1588us`。

**为什么撑杆高度（`5CM架台`）很关键**：撑杆抬高会**放大**同样的舵机转动量
对应的倾角变化，等效于提高整个位置环的增益。机构和软件增益是耦合的——
换机构必须重新整定 PID，不能直接沿用旧参数。

**视觉支架**的安装角度需要保证摆杆在相机画面中**接近水平**。轴线若在画面里
明显倾斜，`ball_position.py` 的"沿轴正交投影"仍能算对轴向位置，但标定轴
两端点的像素坐标必须跟着重新标。

## 使用说明

1. **查看装配**：用 SolidWorks 打开 `26电赛.SLDASM`。若提示找不到零件，
   把所有文件放在同一目录下再打开。
2. **直接打印**：用 `printables_step/` 里的 STEP 文件导入切片软件，
   无需 SolidWorks。STEP 是中性格式，SolidWorks / Fusion / FreeCAD / PrusaSlicer
   都能读。
3. **改动设计**：修改 `SLDPRT` 后需要重新导出 STEP。

> **打印参数未记录。** 作者未保留当时的层高、填充率、材料与支撑设置。
> 根据零件受力情况的一般建议：底盘与支架类承力件用较高填充率，
> 摆杆转轴座与撑杆配合面注意层纹方向以获得更好的抗弯强度。
