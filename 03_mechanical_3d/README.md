# 03 · 机械结构 3D 模型

车载平衡滚球小车的完整机械设计：底盘、车架、舵机支架、摆杆机构、视觉支架。
全部为自主建模

- **CAD**：SolidWorks（`*.SLDPRT` 零件 / `*.SLDASM` 装配体）
- **交换格式**：`printables_step/` 下 9 个 `*.STEP`，可直接切片打印

## 目录

```
26电赛.SLDASM              总装配体（从这个文件开始看）
*.SLDPRT                   18 个零件
printables_step/           9 个可打印 STEP
```

## 机构要点

舵机旋转经 `舵盘摆臂杆` → `摆杆撑杆` 转成摆杆俯仰。舵机脉宽与倾角近似线性
（500–2500us 对应 0–180°），主控侧水平点标定值为 `1588us`。

撑杆高度会放大同样的舵机转动量对应的倾角变化，等效于改变整个位置环的增益，
**换机构必须重新整定 PID**。

视觉支架的安装角度需保证摆杆在画面中接近水平，否则 `AXIS_*_PX` 要重新标定。

## 使用

1. **看装配**：SolidWorks 打开 `26电赛.SLDASM`，若提示找不到零件，
   把所有文件放同一目录再打开。
2. **直接打印**：用 `printables_step/` 里的 STEP 导入切片软件即可，
   无需 SolidWorks（Fusion / FreeCAD / PrusaSlicer 都能读）。

> 打印参数（层高、填充率、材料、支撑）当时未记录。一般建议承力件用较高填充率，
> 转轴座与撑杆的配合面注意层纹方向以获得更好的抗弯强度。

## 注意

`10kg高速舵机.SLDPRT` 与 `25T 塑料舵盘.SLDPRT` 是外购标准件的参考模型，
用于装配干涉检查，不是打印件，版权归原厂商。
